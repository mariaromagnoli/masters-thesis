A batch is a worker's own co-hire SET: the people her preloaded roster row
names, i.e. the co-hires she had access to. Counts are over members of
that set.

rostered    = size of the set
cell        = workers whose OWN row lists this exact set. Equal to rostered
              when every member names the same set, which marks the batch
              as a closed hiring line (line = TRUE)
interviewed = members who completed an interview
excluded    = of those, dropped as problem records ("00 config.R")
usable      = interviewed and not excluded
typed       = usable members whose birth woreda is observed; the survey
              never asks an ego about a co-hire's origin, so only these
              carry an origin label
coverage    = typed / rostered
